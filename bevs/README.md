# BEV visualizations

See [`CATALOG.md`](./CATALOG.md) (and the machine-readable [`catalog.json`](./catalog.json)) for the full per-file inventory with representation, training scale, seed, source checkpoint, and known ADE/FDE numbers for every BEV under this directory.

Bird's-eye-view (BEV) qualitative results from across the project's experimental phases. Each BEV shows ground-truth ego trajectory (green), model prediction (red dashed), the ego's $t=0$ position (blue dot), and where applicable the reference centerline (gray dashed).

All visualizations were generated by `scripts/visualize_bev.py` (static) or `scripts/visualize_bev_gif.py` (animated rollouts) on the team's preprocessed nuPlan-mini cache.

## Scene IDs

Scene indices (12, 57, 125, 140) refer to positions in the alphabetically-sorted preprocessed `.npz` cache used during evaluation. They are deterministic given the same cache, so the same scene index always refers to the same scenario.

## Reference centerline (Frenet only)

Frenet BEVs include a gray dashed curve representing the smart-selected reference centerline used by the model at training and decoding time. The prediction is generated in Frenet coordinates $(s, d)$ relative to this centerline and decoded back to Cartesian for visualization and metric computation.
